# Student Life Hub Privacy Notice

## Data storage

Student Life Hub is designed to work offline. Tasks, classes, events,
expenses, attendance, grades, profile settings, and backups are stored locally
on the device or in the browser's local storage. The app does not require an
account or send student records to a server.

## Photos and files

Profile photos and attachments selected by the user remain on the device. The
app only accesses a file after the user chooses it through the operating
system picker.

## Notifications

Task reminders are scheduled locally by the operating system. Notification
content is not uploaded to a cloud service. Users can revoke notification
permission in system settings.

## Backups

Plain JSON backups contain the records selected for export and should be
treated as sensitive. Encrypted backups use a password and authenticated
AES-256-GCM encryption. Student Life Hub does not know or recover a forgotten
backup password.

## Diagnostics

The app stores a small last-error diagnostic locally to help troubleshoot
failures. It is not transmitted automatically. Users can remove it by
resetting local app data.

## Contact

For privacy questions, contact the project owner through the contact details
listed in the About page.
